# v1.1.0 core changes

- Reset clears the active calibration value, calibration comment, and maturation note while retaining historical records.
- Sensor stale timeout is configurable per maturation counter (15–1440 minutes, default 120). It is available in the Options flow and as a Number entity for dashboard/card control.
- When the selected temperature sensor is stale or unavailable, the counter continues using the last known valid temperature when one exists.
- Sensor health still changes to `stale` or `unavailable` and triggers the existing notification.
- If no valid temperature has ever been received, accumulation cannot continue.
- Version bumped to 1.1.0.
